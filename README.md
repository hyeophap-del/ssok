# Galaxy File

같은 Wi-Fi에 있는 **PC와 휴대폰, PC와 PC 사이에서 파일과 텍스트를 무선으로 주고받는** 작은 프로그램입니다.
휴대폰에는 앱을 설치할 필요가 없고, PC에 뜬 QR 코드를 카메라로 찍으면 브라우저에서 바로 열립니다.

- 휴대폰 → PC: 사진·동영상·파일을 여러 개 한꺼번에 보내면 PC의 `다운로드\Galaxy File` 폴더에 저장됩니다. 사진 찍은 날짜도 그대로 유지됩니다.
- PC → 휴대폰: 파일을 PC 화면에 끌어다 놓거나, 캡처한 화면을 `Ctrl+V`로 붙여 넣으면 휴대폰에서 바로 받을 수 있습니다.
- PC → PC: 두 PC에서 모두 Galaxy File을 켜 두면 서로를 자동으로 찾습니다. 처음 한 번만 연결해 두면, 보낼 곳을 고르고 끌어다 놓는 것만으로 상대 PC의 `다운로드\Galaxy File` 폴더에 바로 저장됩니다.
- 텍스트·링크: 어느 쪽에서 보내든 상대 화면에 바로 뜨고, 버튼 하나로 복사할 수 있습니다.
- 실시간: 보내는 즉시 상대 화면에 나타나고 알림이 뜹니다. 전송 속도와 남은 시간도 보여 줍니다.

## 실행하기

필요한 것: [Node.js](https://nodejs.org) 20 이상 (다른 패키지 설치는 필요 없음)

1. **`start.bat`을 더블클릭**합니다. 터미널에서는 `npm start`로도 실행할 수 있습니다.
2. 처음 실행할 때 **Windows 방화벽 창이 뜨면 ‘허용’**을 누릅니다. 이걸 눌러야 휴대폰이 PC에 접속할 수 있습니다.
3. PC 브라우저에 Galaxy File 화면이 열립니다. **휴대폰 카메라로 화면의 QR 코드를 스캔**하세요.
4. 휴대폰 브라우저 메뉴(⋮)에서 **‘홈 화면에 추가’**를 해 두면, 다음부터는 아이콘만 누르면 바로 열립니다.

> PC에서 Galaxy File이 실행 중일 때만 주고받을 수 있습니다. 실행 창을 닫으면 공유가 멈춥니다.
> 이미 실행 중일 때 `start.bat`을 다시 누르면 새로 띄우지 않고 기존 화면을 열어 줍니다.

## PC끼리 주고받기

1. 다른 PC에도 Node.js를 설치하고 이 폴더를 복사한 뒤 **`start.bat`을 실행**합니다. (방화벽 창이 뜨면 ‘허용’)
2. 한쪽 PC 화면에서 **보낼 곳 → ‘+ 다른 PC’**를 누르면 같은 네트워크에서 켜져 있는 PC가 목록에 나타납니다. **[연결]**을 누르세요.
3. 상대 PC 화면에 **연결 요청 창**이 뜹니다. 두 화면의 **네 자리 숫자가 같은지** 확인하고 **[허용]**을 누르세요.
   상대 PC에서 Galaxy File 화면이 닫혀 있으면 자동으로 열립니다.
4. 이제 보낼 곳에서 그 PC를 고르고 파일을 끌어다 놓거나, `Ctrl+V`로 붙여 넣거나, 텍스트를 보내면 바로 상대 PC에 저장됩니다.
   반대 방향도 똑같이 됩니다. 연결은 기억되므로 다음부터는 1~3단계가 필요 없습니다.

- 목록에 PC가 안 보이면(공유기가 기기 찾기를 막는 경우 등) 연결 창 아래에 **상대 PC의 주소**를 직접 넣으세요.
  각 PC의 주소는 연결 창 맨 아래 ‘이 PC는 … · 주소 …’에 나옵니다.
- 다른 PC에 보일 이름은 컴퓨터 이름이 기본입니다. `start.bat --name "거실 PC"`처럼 바꿀 수 있습니다.
- 상대 PC에 아무것도 설치하고 싶지 않다면, 그 PC의 브라우저에서 휴대폰용 주소(QR 아래 주소)를 열어도 됩니다. 이때는 휴대폰처럼 동작합니다.

## 휴대폰에서 접속이 안 될 때

1. **PC와 휴대폰이 같은 Wi-Fi(공유기)에 연결되어 있는지** 확인하세요. 게스트 Wi-Fi는 기기끼리 통신이 막혀 있는 경우가 많습니다.
2. **Wi-Fi가 ‘공용 네트워크’로 설정되어 있으면** 방화벽이 접속을 막을 수 있습니다. 집 Wi-Fi라면
   `설정 → 네트워크 및 인터넷 → Wi-Fi → 연결된 Wi-Fi 속성`에서 **‘개인 네트워크’**로 바꾸세요.
   이 경우 Galaxy File이 PC 화면과 실행 창에 경고를 띄워 줍니다.
3. 방화벽 창에서 실수로 ‘취소’를 눌렀다면:
   `Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용 → 설정 변경`에서 **Node.js JavaScript Runtime**을 찾아 체크하세요.
4. PC에 네트워크가 여러 개(유선+무선, VPN 등)라면 PC 화면의 ‘네트워크’ 목록에서 다른 주소를 골라 다시 스캔해 보세요.
5. 큰 파일을 보내는 동안에는 휴대폰 화면을 켜 두세요. 화면이 꺼지면 브라우저가 전송을 멈출 수 있습니다.

PC의 IP 주소가 바뀌면 홈 화면 바로가기가 열리지 않을 수 있습니다. 그럴 땐 QR 코드를 다시 스캔하세요.
공유기 설정에서 PC에 고정 IP(DHCP 예약)를 걸어 두면 주소가 바뀌지 않습니다.

## 옵션

```
node server.js [옵션]        (start.bat 뒤에 붙여도 됩니다)

  --dir <폴더>      받은 파일을 저장할 폴더 (기본: 다운로드\Galaxy File, 한 번 정하면 기억)
  --port <번호>     사용할 포트 (기본: 8765)
  --no-open         시작할 때 브라우저를 열지 않음
  --reset-token     접속 코드를 새로 만듦 (연결했던 휴대폰은 QR을 다시 스캔해야 함)
  --host <주소>     접속을 받을 주소 (기본: 모든 네트워크, 127.0.0.1이면 이 PC에서만)
  --name <이름>     다른 PC에 보일 이 PC의 이름 (기본: 컴퓨터 이름, 한 번 정하면 기억)
```

## 보안

- QR 코드에는 PC마다 무작위로 만든 **접속 코드**가 들어 있습니다. 이 코드가 없으면 같은 Wi-Fi에 있는 다른 사람도 접속할 수 없습니다.
  QR 화면을 다른 사람에게 보여 줬다면 `--reset-token`으로 코드를 바꾸세요.
- 다른 웹사이트가 몰래 이 프로그램에 요청을 보내는 공격(CSRF, DNS 리바인딩)을 막고, 받은 HTML·SVG 파일은 브라우저에서 격리된 채로만 열립니다.
- PC끼리는 **상대 화면에서 허용해야만** 연결되고, 연결할 때 두 PC가 각자 만든 비밀 키를 주고받습니다. 그 뒤로는 이 키가 있는 요청만 받아들입니다.
  같은 네트워크의 다른 기기가 연결된 PC인 척 주소를 바꿔치기하지 못하도록, 상대 PC의 주소가 바뀌면 키로 확인한 뒤에만 새 주소를 씁니다.
  한쪽에서 연결을 해제하면 양쪽 모두에서 키가 지워집니다.
- 같은 Wi-Fi 안에서 **암호화되지 않은 HTTP**로 주고받습니다. 집이나 사무실처럼 믿을 수 있는 네트워크에서 쓰고,
  카페·공항 같은 공용 Wi-Fi에서는 쓰지 마세요.

## 파일 위치

| 무엇 | 어디 |
| --- | --- |
| 휴대폰에서 받은 파일 | `다운로드\Galaxy File` (또는 `--dir`로 정한 폴더) |
| 설정(접속 코드·포트) | `%LOCALAPPDATA%\GalaxyFile\config.json` |
| 주고받은 목록 | `%LOCALAPPDATA%\GalaxyFile\items.json` |
| 연결된 PC와 키 | `%LOCALAPPDATA%\GalaxyFile\peers.json` |
| PC에서 휴대폰으로 보낸 파일의 임시 사본 | `%LOCALAPPDATA%\GalaxyFile\outbox` (목록에서 지우면 함께 지워짐) |

목록에서 항목을 지워도 **휴대폰에서 받은 원본 파일은 폴더에 그대로 남습니다.**

## 개발

```
npm install   # 테스트용 QR 디코더(jsQR)만 설치됩니다. 실행에는 필요 없습니다.
npm test
```

| 파일 | 역할 |
| --- | --- |
| `server.js` | 실행 진입점: 설정, 포트 선택, 터미널 QR, 종료 처리 |
| `src/app.js` | HTTP 서버: 인증, 업로드·다운로드(Range 지원), 실시간 알림(SSE) |
| `src/peer-api.js` | PC끼리 연결(페어링)·해제, 연결된 PC로 파일·텍스트 중계, 바뀐 주소 확인 |
| `src/peers.js` | 연결된 PC·주변 PC 목록, PC끼리 쓰는 요청 도구 |
| `src/discovery.js` | 같은 네트워크의 Galaxy File 자동 찾기 (UDP 8765 브로드캐스트) |
| `src/http.js` | 응답·본문 읽기 같은 공통 HTTP 도구 |
| `src/qr.js` | 외부 의존성 없는 QR 코드 생성기 (SVG·터미널 출력) |
| `src/files.js` | 파일 이름 정리, 이름 겹침 처리, MIME |
| `src/net.js` | 휴대폰이 접속할 IP 고르기, Host 헤더 검사 |
| `src/store.js` | 주고받은 목록 저장 |
| `src/open.js`, `src/windows.js` | 탐색기·브라우저 열기, 공용 네트워크 감지 |
| `public/` | 웹 화면 (PC·휴대폰 공용) |
| `scripts/make-icons.mjs` | `icon.svg`와 같은 모양의 PNG 아이콘 생성 |
