# 쏙 (Ssok)

같은 Wi-Fi에 있는 **PC와 휴대폰, PC와 PC 사이에서 파일과 텍스트를 무선으로 주고받는** 작은 프로그램입니다.
휴대폰에는 앱을 설치할 필요가 없고, PC에 뜬 QR 코드를 카메라로 찍으면 브라우저에서 바로 열립니다.

- 휴대폰 → PC: 사진·동영상·파일을 여러 개 한꺼번에 보내면 PC의 `다운로드\쏙` 폴더에 저장됩니다. 사진 찍은 날짜도 그대로 유지됩니다.
- PC → 휴대폰: 파일을 PC 화면에 끌어다 놓거나, 캡처한 화면을 `Ctrl+V`로 붙여 넣으면 휴대폰에서 바로 받을 수 있습니다.
- PC → PC: 두 PC에서 모두 쏙을 켜 두면 서로를 자동으로 찾습니다. 처음 한 번만 연결해 두면, 보낼 곳을 고르고 끌어다 놓는 것만으로 상대 PC의 `다운로드\쏙` 폴더에 바로 저장됩니다. PC끼리는 항상 암호화됩니다.
- 텍스트·링크: 어느 쪽에서 보내든 상대 화면에 바로 뜨고, 버튼 하나로 복사할 수 있습니다.
- 실시간: 보내는 즉시 상대 화면에 나타나고 알림이 뜹니다. 전송 속도와 남은 시간도 보여 줍니다.

**[⬇ 최신 버전 내려받기 (Windows)](https://github.com/hyeophap-del/ssok/releases/latest)** — `Ssok-<버전>.exe` 하나만 받으면 됩니다.

## 설치와 실행

**exe로 설치할 때** (Node.js 설치 필요 없음)

1. [릴리스 페이지](https://github.com/hyeophap-del/ssok/releases/latest)에서 받은 **`Ssok-<버전>.exe`를 더블클릭**합니다.
   프로그램이 `%LOCALAPPDATA%\Programs\Ssok`에 스스로 설치되므로, 받은 exe는 지워도 됩니다.
   - "Windows의 PC 보호" 창이 뜨면 **[추가 정보] → [실행]** 을 누르세요 (코드 서명이 없어서 뜨는 경고입니다).
   - **Windows 방화벽 창에 ‘쏙’이 뜨면 ‘허용’** 을 누르세요. 그래야 휴대폰과 다른 PC가 접속할 수 있습니다.
2. 브라우저에 PC 화면이 열립니다. **휴대폰 카메라로 QR 코드를 스캔**하세요.
3. 휴대폰 브라우저 메뉴(⋮)에서 **‘홈 화면에 추가’** 를 해 두면, 다음부터는 아이콘만 누르면 바로 열립니다.

처음 실행하면 **시작 메뉴에 ‘쏙’** 이 생기고, **PC를 켤 때 창 없이 자동으로 실행**됩니다. 휴대폰에서 보내려면 PC에서 쏙이 켜져 있어야 하기 때문입니다.
화면을 다시 열려면 시작 메뉴에서 ‘쏙’을 누르세요. 자동 실행 끄기와 프로그램 끄기는 PC 화면의 **[설정]** 에 있습니다.
**업데이트**: 새 버전이 나오면 PC 화면 맨 위에 **“새 버전이 있어요 [업데이트]”** 가 뜹니다 (하루에 한 번 확인, [설정]에서 끌 수 있음).
누르면 내려받아 스스로 바꾸고 화면이 새로 고쳐집니다. 설정과 연결은 그대로 남습니다.
받은 파일은 우리 업데이트 서명 키로 서명했는지, 올린 파일과 똑같은지(SHA-256)를 확인한 뒤에만 설치합니다.
새 버전의 exe를 직접 받아 실행해도 똑같이 바뀝니다. 휴대폰 앱은 PC가 업데이트되면 앱 화면에 “새 버전 앱이 있어요”가 뜨고, [새 버전 받기]를 누르면 PC에서 암호화된 연결로 받아 바로 설치합니다 (처음 한 번은 ‘이 출처의 앱 설치 허용’을 켜야 합니다).

**이 저장소에서 바로 실행할 때** (Node.js 20 이상 필요): `start.bat`을 더블클릭하면 위와 똑같이 동작합니다.
실행 기록을 창에서 보고 싶으면 `npm start`(= `node server.js`)로 실행하세요.

**나눠 줄 파일 만들기**
- `npm run exe` → `dist\쏙.exe` (약 96MB, 파일 하나): 이 PC의 Node.js에 쏙을 넣어 만든 실행 파일입니다.
  창 없는 프로그램이고, 아이콘과 이름이 ‘쏙’으로 보입니다. 서명이 없어서 처음 실행할 때 Windows 경고가 뜹니다.
- `npm run package` → `dist\Ssok-<버전>-windows-x64.zip` (약 38MB): 공식 `node.exe`(OpenJS 재단 서명)를 그대로 넣은 압축 파일입니다.
  압축을 풀고 `쏙 시작`을 더블클릭합니다. exe가 백신에 잘못 걸리는 PC라면 이쪽을 쓰세요.

## 휴대폰 앱 (안드로이드)

브라우저 대신 앱을 쓰면 **갤러리에서 공유 → 쏙** 한 번으로 PC에 보낼 수 있고, 화면이 꺼져도 끝까지 보냅니다. 앱과 PC 사이는 암호화됩니다.

1. 휴대폰으로 PC 화면의 QR 코드를 찍어 열린 화면에서 **① 앱 설치 파일 받기**를 누르고 설치합니다.
   (처음 한 번 ‘출처를 알 수 없는 앱 설치’ 허용이 필요합니다. 앱 파일은 PC의 쏙이 직접 내려줍니다.)
2. 같은 화면에서 **② 앱에 이 PC 연결**을 누르면 앱이 열리고 6자리 숫자가 뜹니다.
   PC 화면에도 같은 숫자의 연결 요청이 뜨면 **[허용]** 을 누르세요.
3. 이제 갤러리·파일 앱에서 보낼 것을 고르고 **공유 → 쏙**을 누르면 됩니다. 진행률과 결과는 알림으로 보여 줍니다.

PC의 IP 주소가 바뀌어도 앱이 같은 Wi-Fi에서 그 PC를 다시 찾습니다. 이때 처음 연결할 때 기억한 인증서로 진짜 그 PC인지 확인합니다.
QR 화면이 아니어도, 앱의 [PC 주소로 직접 연결]에 PC 주소(예: 192.168.0.32)를 넣어 연결할 수 있습니다.

**집 밖에서도**: PC에서 ‘어디서나 (중계 서버)’를 켜 두면, 앱이 그 중계 서버를 거쳐 보냅니다.
데이터(LTE·5G)로 연결되어 있으면 바로 중계 서버로, Wi-Fi인데 PC가 안 보이면 같은 방법으로 찾아 본 뒤 중계 서버로 보냅니다.
앱과 PC가 연결할 때 나눠 가진 키로 종단간 암호화하므로 중계 서버는 내용을 볼 수 없습니다.
PC에서 중계 서버를 나중에 켰다면, 같은 Wi-Fi에서 앱을 한 번 열면 그 주소를 알아 둡니다 (앱의 PC 카드에 ‘어디서나’가 표시됩니다).

## 아이폰: 사진 앱의 공유 메뉴에서 보내기

아이폰 앱은 Mac과 애플 개발자 등록이 있어야 만들 수 있어서, 대신 아이폰 기본 앱인 **단축어**를 씁니다.
아이폰으로 PC 화면의 QR 코드를 찍어 열린 화면에서 **‘아이폰: 사진 앱의 공유 메뉴에서 바로 보내기’** 를 펼치면,
이 PC 전용 주소와 함께 단축어를 만드는 6단계가 나옵니다. 한 번 만들어 두면 **공유 → 쏙으로 보내기**로 사진·동영상·파일·텍스트를 보낼 수 있습니다.
(집 Wi-Fi 주소의 단축어는 암호화하지 않은 HTTP로 보내므로 집 Wi-Fi나 핫스팟에서 쓰세요.)

**집 밖에서도**: PC에서 ‘어디서나 (중계 서버)’를 켜 두면, 안내에 나오는 주소가 **중계 서버 주소**(`https://…/s/…`)로 바뀌어
그 단축어 하나로 집에서도 밖에서도 보낼 수 있습니다. 다만 한 번에 **100MB까지**(Cloudflare 무료 요금제의 한도)이고,
이 경로는 휴대폰과 중계 서버 사이만 HTTPS로 암호화됩니다 (단축어가 직접 암호화할 수 없어서, 중계 서버가 내용을 볼 수 있음).
집 Wi-Fi에서 큰 동영상을 보낼 단축어는 안내 아래의 집 전용 주소로 하나 더 만들어 두면 됩니다.
아이폰 **브라우저 화면**([어디서나] QR)으로 보내는 것은 크기 제한이 없고 종단간 암호화됩니다.

## PC끼리 주고받기

1. 두 PC 모두에서 쏙을 실행합니다.
2. 한쪽 PC 화면에서 **보낼 곳 → ‘+ 다른 PC’** 를 누르면 같은 네트워크에서 켜져 있는 PC가 목록에 나타납니다. **[연결]** 을 누르세요.
3. 상대 PC 화면에 **연결 요청 창**이 뜹니다 (닫혀 있었으면 자동으로 열립니다). 두 화면의 **6자리 숫자가 같은지** 확인하고 **[허용]** 을 누르세요.
   숫자가 다르면 누군가 중간에 끼어든 것일 수 있으니 거절하세요.
4. 이제 보낼 곳에서 그 PC를 고르고 파일을 끌어다 놓거나, `Ctrl+V`로 붙여 넣거나, 텍스트를 보내면 바로 상대 PC에 저장됩니다.
   반대 방향도 똑같이 됩니다. 연결은 기억되므로 다음부터는 1~3단계가 필요 없습니다.

- 목록에 PC가 안 보이면(공유기가 기기 찾기를 막는 경우 등) 연결 창 아래에 **상대 PC의 주소**를 직접 넣으세요.
  각 PC의 주소는 연결 창 맨 아래 ‘이 PC는 … · 주소 …’에 나옵니다.
- **집 밖에서도**: 받는 PC가 [설정]의 ‘어디서나 (중계 서버)’를 켜 두었다면, 같은 네트워크에 없을 때도 그 PC를 골라 그대로 보낼 수 있습니다.
  보낼 곳의 PC 이름 옆 점이 **파란색**이면 중계 서버를 거쳐 보냅니다 (초록색은 같은 네트워크에서 바로).
  연결할 때 서로의 중계 서버 주소도 알려 둡니다.
- **다른 곳에 있는 PC와 처음 연결하기**: 두 PC 모두 ‘어디서나 (중계 서버)’를 켜 둔 상태에서,
  한쪽 PC의 연결 창에서 **[이 PC의 연결 코드 만들기]** 를 누릅니다. 나온 코드(예: `ABCD-EFGH`, 10분 동안 유효)를
  다른 PC의 연결 창 맨 아래 칸에 넣고 [연결]을 누르면, 위 3단계처럼 6자리 숫자를 확인하고 [허용]하면 됩니다.
  두 PC가 서로 다른 중계 서버를 쓴다면 코드 앞에 상대의 중계 서버 주소를 붙입니다 (`ssok.example.com/ABCD-EFGH`).
- 다른 PC에 보일 이름은 PC 화면의 [설정]에서 바꿀 수 있습니다.
- 상대 PC에 아무것도 설치하고 싶지 않다면, 그 PC의 브라우저에서 휴대폰용 주소(QR 아래 주소)를 열어도 됩니다. 이때는 휴대폰처럼 동작합니다.

## 홈페이지에서 바로 주고받기: 설치 없이 브라우저끼리

중계 서버의 홈페이지(예: `https://ssok.example.com`)에 들어가면 **아무것도 설치하지 않고** 여러 기기(한 방에 10대까지)가 주고받을 수 있습니다.

1. 중계 서버 관리 화면의 **홈페이지에서 바로 주고받기**에서 숫자 4자리 암호를 정합니다 (정해야 켜집니다).
2. 한 기기에서 홈페이지에 들어가 암호를 넣고 **[새로 시작하기]** 를 누르면 6자리 방 코드와 QR이 나옵니다.
3. 다른 기기들은 홈페이지에 들어가 암호를 넣고 방 코드를 넣거나, 휴대폰 카메라로 QR을 찍습니다. 주고받는 중에도 **[더 초대]** 로 코드를 다시 볼 수 있습니다.
4. 이제 모든 기기가 사진·파일·텍스트를 보낼 수 있습니다. **보낼 곳**에서 ‘모두’ 또는 한 기기를 고르세요.
   받은 파일은 **[저장]** 을 눌러 저장하세요 (창을 닫으면 사라집니다).

방에서 보일 **내 이름**(예: 민수 노트북)은 들어가기 전에 정하거나, 방 안에서 **[이름]** 으로 바꿀 수 있습니다 (브라우저가 기억).
보내는 쪽 진행 막대는 받는 기기들이 실제로 받은 양을 보여 줍니다. 받지 못하고 멈춘 기기가 있으면 15초 뒤 그 기기를 빼고 나머지에 마저 보내고,
잠든 휴대폰처럼 말없이 끊긴 기기는 1분 안에 방에서 빠집니다.

암호를 한 번 맞게 넣은 브라우저는 30일 동안 기억합니다. 암호를 바꾸면 모두 다시 넣어야 하고, 한 곳에서 10번 틀리면 10분 동안 막힙니다.
방은 10분 동안 아무도 들어오지 않으면 닫히고, 한 번 모인 뒤에는 모두 나갈 때까지 열려 있습니다 (방을 만든 기기가 나가도 남은 기기끼리 계속).
방을 만든 기기가 ‘방 열쇠’를 만들고, 새로 들어온 기기에는 그 자리에서 만든 열쇠(ECDH)로 감싸 건네므로 내용은 암호화되어 오가고 어디에도 저장되지 않습니다.
다만 열쇠를 건네는 과정은 중계 서버를 거치므로, 중계 서버를 운영하는 사람이 마음먹고 끼어드는 것까지 막지는 못합니다 (자기 중계 서버라면 걱정하지 않아도 됩니다).
‘모두’에게 보내면 한 번만 올려도 중계 서버가 나눠 주지만, 그만큼 중계 서버 쪽 인터넷으로 여러 번 나가고 가장 느린 기기에 속도가 맞춰집니다.
받는 파일은 브라우저 메모리에 모았다가 저장하므로, 휴대폰에서는 아주 큰 파일(1GB 넘게)이 실패할 수 있습니다.

## 링크로 주고받기: 쏙이 없는 사람과

지인처럼 쏙을 쓰지 않는 사람과도 **`ssok.example.com/minsu` 같은 링크와 비밀번호**로 웹에서 주고받을 수 있습니다.
어디서든(LTE·5G, 다른 Wi-Fi) 되고, 그 사람은 설치할 것이 없습니다.

1. ‘어디서나 (중계 서버)’를 켠 PC 화면의 **링크로 주고받기** 카드에서 **[+ 새 링크]** 를 누릅니다.
   누구에게(예: 민수), 링크 주소(예: `minsu`, 비우면 짧은 이름을 자동으로), 비밀번호(6자 이상, 숫자 6자리가 미리 채워짐), 기간(1·7·30일, 끌 때까지)을 정하고 [링크 만들기]를 누르면
   주소와 비밀번호가 함께 복사됩니다. 카카오톡 등으로 보내 주세요.
2. 받은 사람이 링크를 열고 비밀번호를 한 번 넣으면(그 브라우저는 기억), 사진·파일·텍스트를 이 PC로 보낼 수 있습니다.
3. 이 PC에서 보낼 곳으로 **민수**를 고르고 보내면, 민수의 링크 화면 ‘받은 것’에 나타나 받아 갈 수 있습니다 (받아 갈 수 있게 이 PC를 켜 두세요).

링크를 받은 사람은 **내가 그 사람에게 보낸 것만** 볼 수 있고, 이 PC의 다른 목록이나 파일은 볼 수 없습니다.
링크 상대에게 보낸 것은 내 휴대폰 목록에도 섞이지 않습니다. 비밀번호를 10번 틀리면 그 링크는 10분 동안 막히고, 또 막힐 때마다 두 배로(하루까지) 길어지며,
막힐 때마다 PC 화면(창이 닫혀 있으면 알림 영역 말풍선)으로 알려 줍니다. PC 화면의 비밀번호는 [비밀번호 보기]를 눌러야 보입니다.
카드의 **[끄기]** 를 누르거나 기간이 지나면 바로 쓸 수 없게 되고, 그 사람에게 보내 두었던 파일도 지워집니다. 링크 주소는 중계 서버 안에서 겹치지 않게 먼저 정한 사람이 씁니다.

## 휴대폰에서 접속이 안 될 때

1. **PC와 휴대폰이 같은 Wi-Fi(공유기)에 연결되어 있는지** 확인하세요. 게스트 Wi-Fi는 기기끼리 통신이 막혀 있는 경우가 많습니다.
2. **Wi-Fi가 ‘공용 네트워크’로 설정되어 있으면** 방화벽이 접속을 막을 수 있습니다. 집 Wi-Fi라면
   `설정 → 네트워크 및 인터넷 → Wi-Fi → 연결된 Wi-Fi 속성`에서 **‘개인 네트워크’** 로 바꾸세요.
   이 경우 쏙이 PC 화면에 경고를 띄워 줍니다.
3. 방화벽 창에서 실수로 ‘취소’를 눌렀다면:
   `Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용 → 설정 변경`에서 **Node.js JavaScript Runtime**을 찾아 체크하세요.
4. PC에 네트워크가 여러 개(유선+무선, VPN 등)라면 PC 화면의 ‘네트워크’ 목록에서 다른 주소를 골라 다시 스캔해 보세요.
5. 큰 파일을 보내는 동안에는 휴대폰 화면을 켜 두세요. 화면이 꺼지면 브라우저가 전송을 멈출 수 있습니다.
   4MB가 넘는 파일은 보내다 끊겨도(와이파이를 벗어남, 화면이 꺼짐 등) **받은 데부터 이어 보냅니다**: 연결이 돌아오면 저절로 이어 가고,
   화면을 새로 열었다면 같은 파일을 다시 고르면 됩니다. PC는 받다 만 파일을 24시간 동안 남겨 둡니다 (받은 파일 폴더 안의 숨긴 폴더).

PC의 IP 주소가 바뀌면 홈 화면 바로가기가 열리지 않을 수 있습니다. 그럴 땐 QR 코드를 다시 스캔하세요.
공유기 설정에서 PC에 고정 IP(DHCP 예약)를 걸어 두면 주소가 바뀌지 않습니다.

## 집 밖에서 쓸 때

휴대폰이 LTE·5G로 밖에 있거나, 회사·카페·게스트 Wi-Fi처럼 기기끼리 통신이 막힌 곳에서도 보내는 방법이 두 가지 있습니다.

### 어디서나 보내기 (중계 서버) — 휴대폰엔 아무것도 깔지 않아도 됨

늘 켜 둔 Windows PC 한 대(예: 본가 PC)를 **중계 서버**로 두고, Cloudflare에 등록한 내 도메인(예: `ssok.example.com`)으로 인터넷에 내보냅니다.
공유기 포트 열기는 필요 없습니다. 중계 서버 하나를 여러 사람(지인)이 초대 코드로 함께 쓸 수 있습니다.

**중계 서버 PC에서 (한 번만)**

1. [릴리스](https://github.com/hyeophap-del/ssok/releases/latest)에서 `SsokRelay-<버전>.exe`를 내려받아 실행합니다.
   스스로 설치되고 **쏙 중계 서버** 관리 화면이 열립니다 (시작 메뉴 ‘쏙 중계 서버’, Windows에 로그인하면 자동 실행).
2. [인터넷 주소]에 도메인 앞에 이름을 붙인 주소(예: `ssok.example.com`)를 넣고 **[연결하기]** 를 누릅니다.
   Cloudflare 프로그램(cloudflared)을 내려받은 뒤 브라우저에 Cloudflare 로그인 창이 뜹니다.
   로그인하고 **그 도메인을 골라 [Authorize]** 를 누르면, 터널과 DNS를 만들고 켜는 것까지 알아서 합니다.
   ‘바깥에서 접속: 잘 돼요’가 보이면 끝입니다 (DNS가 퍼지는 데 1~2분 걸릴 수 있어요).
3. [초대 코드]에서 쓸 사람마다 코드를 하나씩 만들어 알려 줍니다. 코드를 막으면 그 사람의 PC들은 바로 끊깁니다.

중계 서버 PC는 잠자기 모드로 들어가지 않게 하고, Windows에 로그인된 상태로 두세요(원격 데스크톱 연결을 끊는 것은 괜찮습니다).
새 버전이 나오면 주고받는 사람이 없을 때 스스로 업데이트합니다.

**쏙을 쓰는 PC에서**

1. PC 화면의 [설정] → **‘어디서나 (중계 서버)’** 에 중계 서버 주소와 초대 코드를 넣고 [저장]합니다. ‘● … 연결됨’이 보이면 됩니다.
2. 휴대폰 연결 카드에 **[어디서나]** 탭이 생깁니다. 그 QR을 휴대폰으로 스캔하고 홈 화면에 추가해 두세요. 집에서도 밖에서도 열립니다.

휴대폰과 PC 사이의 내용은 **종단간 암호화**됩니다. 열쇠는 QR 주소의 `#` 뒤에만 있어 어떤 서버로도 보내지지 않으므로,
중계 서버와 Cloudflare는 알아볼 수 없는 바이트를 넘겨주기만 하고 아무것도 저장하지 않습니다.
속도는 중계 서버 쪽 인터넷 업로드 속도에 좌우되므로, 같은 Wi-Fi에 있을 때는 [집 Wi-Fi] QR이 더 빠릅니다.
**연결해 둔 PC끼리**와 **안드로이드 앱**도 집 밖에서 중계 서버를 거쳐 보낼 수 있습니다 (위 ‘PC끼리 주고받기’, ‘휴대폰 앱 (안드로이드)’ 참고).

### 어디서나 보내기 (Tailscale) — 중계 서버가 없을 때

1. 쏙을 켜 둔 PC와 휴대폰에 무료 앱 **Tailscale**을 설치합니다 ([tailscale.com/download](https://tailscale.com/download), 휴대폰은 앱 스토어에서 ‘Tailscale’).
2. 두 기기 모두 **같은 계정**(구글 등)으로 로그인하고 연결을 켭니다.
3. 중계 서버를 설정하지 않았다면, PC 화면의 휴대폰 연결 카드에 **[어디서나 (Tailscale)]** 탭이 생깁니다. 그 QR을 휴대폰으로 스캔하고 홈 화면에 추가해 두세요.
   이 주소는 집에서도 밖에서도 열립니다. 안드로이드 앱은 PC의 Tailscale 주소를 기억해 두었다가 집 밖에서는 그 주소로 보냅니다.
4. PC끼리는 연결 창 아래 ‘주소로 연결’에 상대 PC의 Tailscale 주소(100.으로 시작)를 넣어 연결하면 어디서나 주고받을 수 있습니다.

Tailscale은 기기끼리 직접(안 되면 Tailscale 중계로) 암호화해서 잇는 개인용 VPN이라, 파일은 쏙 서버 같은 곳에 남지 않습니다.
방화벽 창에서 ‘공용 네트워크’를 허용하지 않았다면 Tailscale 쪽 접속이 막힐 수 있으니, 그때는 방화벽에서 쏙을 공용 네트워크에도 허용해 주세요.

**잠깐 쓸 때는 휴대폰 핫스팟**: 카페·회사처럼 여러 사람이 쓰는 Wi-Fi에서는 휴대폰 핫스팟을 켜고 PC를 거기에 연결해서 써도 됩니다.
핫스팟에는 내 기기만 붙고 Wi-Fi 자체가 암호화되어 있어 안전합니다. PC가 공용 네트워크에 연결되어 있으면 PC 화면에 안내가 뜹니다.

## 옵션

```
node server.js [옵션]        (start.bat 뒤에 붙여도 됩니다)

  --launch          창 없이 뒤에서 실행하고 PC 화면을 엶 (start.bat, 시작 메뉴, 자동 실행이 쓰는 방식)
  --dir <폴더>      받은 파일을 저장할 폴더 (기본: 다운로드\쏙, 한 번 정하면 기억)
  --port <번호>     사용할 포트 (기본: 8765)
  --no-open         시작할 때 브라우저를 열지 않음
  --reset-token     접속 코드를 새로 만듦 (연결했던 휴대폰은 QR을 다시 스캔해야 함)
  --host <주소>     접속을 받을 주소 (기본: 모든 네트워크, 127.0.0.1이면 이 PC에서만)
  --name <이름>     다른 PC에 보일 이 PC의 이름 (기본: 컴퓨터 이름, 한 번 정하면 기억)
  --relay           중계 서버로 실행 (관리 화면 http://127.0.0.1:8781, 중계 포트 8780. exe 이름에 Relay가 있으면 저절로)
```

## 보안

- QR 코드에는 PC마다 무작위로 만든 **접속 코드**가 들어 있습니다. 이 코드가 없으면 같은 Wi-Fi에 있는 다른 사람도 접속할 수 없습니다.
  QR 화면을 다른 사람에게 보여 줬다면 `--reset-token`으로 코드를 바꾸세요.
- 다른 웹사이트가 몰래 이 프로그램에 요청을 보내는 공격(CSRF, DNS 리바인딩)을 막고, 받은 HTML·SVG 파일은 브라우저에서 격리된 채로만 열립니다.
- **PC끼리(그리고 휴대폰 앱)는 항상 암호화(HTTPS)** 해서 주고받습니다. 각 PC는 처음 실행할 때 자기 인증서를 만들고,
  연결할 때 받은 상대 인증서를 기억해 둡니다. 그 뒤로는 기억한 인증서가 아닌 상대에게는 아무것도 보내지 않습니다.
- 연결은 **상대 화면에서 허용해야만** 됩니다. 두 화면의 6자리 숫자는 양쪽 인증서로 계산하므로, 중간에서 누가 끼어들면 숫자가 달라집니다.
  한쪽에서 연결을 해제하면 양쪽 모두에서 키가 지워집니다.
- 휴대폰 **브라우저**와는 암호화되지 않은 HTTP로 주고받습니다 (공유기 안에서는 브라우저가 믿는 인증서를 받을 수 없어서).
  집 Wi-Fi나 휴대폰 핫스팟에서 쓰세요.
- **어디서나(중계 서버)** 를 쓰면 휴대폰과 PC가 QR 주소의 `#` 뒤에 든 열쇠(256비트, 서버로 보내지지 않음)로 통로를 만들어
  모든 요청·응답·파일을 AES-GCM으로 암호화합니다. 중계 서버는 내용을 볼 수도, 바꿔치기할 수도 없습니다.
  PC는 초대 코드가 있어야 중계 서버에 붙을 수 있고, 중계로 들어온 휴대폰은 PC 화면 전용 기능(설정·끄기 등)을 쓸 수 없습니다.
  QR 화면을 다른 사람에게 보여 줬다면 `--reset-token`으로 이 열쇠도 함께 바꾸세요.
  단, 휴대폰 화면(웹 페이지)도 중계 서버가 내주므로, 중계 서버 운영자가 화면 코드를 몰래 바꾸면 이 보호를 우회할 수 있습니다.
  **믿을 수 있는 사람이 운영하는 중계 서버만** 쓰세요 (내 중계 서버를 지인과 함께 쓰는 경우라면, 지인은 나를 믿는 셈입니다).
- 연결해 둔 PC끼리, 그리고 안드로이드 앱이 중계로 보낼 때는 연결할 때 나눠 가진 키에서 만든 열쇠로 같은 방식의 암호화 통로를 엽니다.
  중계로 들어온 PC는 파일·텍스트 보내기 같은 PC끼리 기능만 쓸 수 있고, 휴대폰처럼 목록을 보거나 파일을 받아 갈 수는 없습니다.
- 다른 곳의 PC와 **연결 코드로 처음 연결**할 때는, 중계 서버를 거친 통로 안에서 같은 네트워크에서와 똑같이 HTTPS로 연결 과정을 밟습니다.
  연결 코드는 중계 서버도 알 수 있지만 그 안의 HTTPS는 풀 수 없고, 중간에 끼어들면 두 화면의 6자리 숫자가 달라집니다.
  코드를 만든 PC만, 10분 동안만 이런 연결 요청을 받고, 이 통로로는 연결 과정 말고 다른 기능을 쓸 수 없습니다.
- **링크로 주고받기**는 브라우저와 PC가 그 자리에서 만든 열쇠(ECDH)로 같은 방식의 암호화 통로를 엽니다. 비밀번호는 그 통로 안에서만 보내고 PC가 확인합니다.
  QR과 달리 미리 나눈 열쇠가 없으므로, 중계 서버를 운영하는 사람이 마음먹고 끼어드는 것까지 막지는 못합니다.
  이 통로로는 보내기와, 그 링크 상대에게 보낸 것 받기만 되며, PC 쪽 중계 연결과 쏙 서버가 각각 한 번씩 확인해서 막습니다.
  끈 링크와 기간이 지난 링크는 열려 있던 화면에서도 바로 쓸 수 없게 됩니다. 주소에 비밀 열쇠가 없으므로, 비밀번호는 링크와 따로 보내도 좋습니다.
- 아이폰 **단축어**의 어디서나 주소에는 **보내기 전용 열쇠**가 들어 있습니다. 이 열쇠로는 보내기만 되고(목록·받기·설정은 PC 쪽 중계 연결과 쏙 서버가 각각 막음),
  `--reset-token`으로 접속 코드를 바꾸면 함께 바뀝니다. 이 경로만은 중계 서버가 내용을 볼 수 있습니다.
- **홈페이지에서 바로 주고받기**는 주인이 정한 숫자 4자리 암호를 맞힌 브라우저에만 서명한 입장권(쿠키, 30일)을 줍니다. 암호는 한 곳에서 10번,
  전체로 10분에 300번 틀리면 잠시 막습니다. 암호를 아는 사람은 누구나 이 중계 서버(본가 인터넷)로 주고받을 수 있으니 필요한 사람에게만 알려 주세요.
- 중계 서버의 관리 화면은 그 PC 안(127.0.0.1)에서만 열리고, 다른 웹사이트가 몰래 보내는 요청은 거절합니다.
- 자동 업데이트는 GitHub 릴리스의 `latest.json`을 읽고, 프로그램에 넣어 둔 **공개 키로 서명을 확인**한 뒤 exe의 SHA-256까지 맞을 때만 설치합니다.
  GitHub 계정이 털려도 서명 키 없이는 가짜 업데이트를 퍼뜨릴 수 없습니다.

보안 문제를 발견하면 공개 이슈 대신 GitHub의 [비공개 취약점 신고](https://github.com/hyeophap-del/ssok/security/advisories/new)로 알려 주세요.

## 개인 정보

- 파일과 텍스트는 **같은 네트워크 안의 기기끼리만** 오갑니다. 어떤 서버도 거치지 않습니다.
  어디서나(중계 서버)를 설정한 경우에만 그 중계 서버와 Cloudflare를 거치며, 이때도 내용은 종단간 암호화되어 있고 어디에도 저장되지 않습니다.
  중계 서버에는 PC 이름·버전, 초대 코드별 주고받은 양, 마지막 연결 시각, 링크 이름과 그 PC의 짝, 홈페이지 암호가 남고, 기록(relay.log)에는 연결한 PC·기기 이름이 남습니다. 주고받은 내용은 남지 않습니다.
- 쏙이 인터넷에 연결하는 곳은 **하루 한 번 GitHub에서 새 버전을 확인**하는 것뿐입니다([설정]에서 끌 수 있음).
  이때 GitHub는 여느 웹사이트처럼 접속한 IP 주소를 볼 수 있습니다. 안드로이드 앱은 연결한 PC하고만 통신합니다.
- 사용 기록 수집, 광고, 회원 가입이 없습니다. 모든 자료는 이 PC(아래 ‘파일 위치’)와 휴대폰 안에만 있습니다.
- 문제가 생겨 PC 화면 [설정]의 **[문제 기록 열기]** 로 기록을 보낼 때는, 접속 코드를 가린 파일이 열립니다.
  기록에는 주고받은 파일 이름과 기기 이름이 들어 있으니 보내기 전에 한번 훑어보세요.

## 파일 위치

| 무엇 | 어디 |
| --- | --- |
| 휴대폰·다른 PC에서 받은 파일 | `다운로드\쏙` (또는 `--dir`로 정한 폴더) |
| 설정(접속 코드·포트·이름) | `%LOCALAPPDATA%\Ssok\config.json` |
| 주고받은 목록 | `%LOCALAPPDATA%\Ssok\items.json` |
| 연결된 기기와 키·인증서 | `%LOCALAPPDATA%\Ssok\peers.json` |
| 링크 (주소·비밀번호·기간) | `%LOCALAPPDATA%\Ssok\drops.json` |
| 이 PC의 인증서 | `%LOCALAPPDATA%\Ssok\tls-cert.pem`, `tls-key.pem` |
| 실행 기록 | `%LOCALAPPDATA%\Ssok\ssok.log` |
| PC에서 휴대폰으로 보낸 파일의 임시 사본 | `%LOCALAPPDATA%\Ssok\outbox` (목록에서 지우면 함께 지워짐) |
| 중계 서버: 초대 코드·연결한 PC 목록 | `%LOCALAPPDATA%\SsokRelay\relay.json` |
| 중계 서버: Cloudflare 로그인·터널 열쇠 | `%LOCALAPPDATA%\SsokRelay\cloudflared\` (`cert.pem`, `tunnel.json`은 남에게 주지 마세요) |
| 중계 서버: 실행 기록 | `%LOCALAPPDATA%\SsokRelay\relay.log` |

목록에서 항목을 지워도 **받은 원본 파일은 폴더에 그대로 남습니다.**
예전 이름(Galaxy File)으로 쓰던 설정과 `다운로드\Galaxy File` 폴더는 처음 실행할 때 새 이름으로 옮겨집니다.

**지우려면**: PC 화면의 [설정]에서 끄기 → 프로그램 폴더(exe로 설치했다면 `%LOCALAPPDATA%\Programs\Ssok`) 삭제 → 시작 메뉴의 ‘쏙’ 바로가기 삭제
(자동 실행 바로가기는 실행 창(Win+R)에 `shell:startup`을 입력하면 나오는 폴더에 있습니다)

## 개발

```
npm install       # 테스트용 QR 디코더(jsQR)만 설치됩니다. 실행에는 필요 없습니다.
npm test
npm run exe       # 나눠 줄 exe 만들기 (esbuild·resedit는 개발할 때만 씀)
npm run package   # 나눠 줄 압축 파일 만들기
npm run android   # 안드로이드 앱 빌드 → public/ssok.apk
npm run release -- --notes-file 바뀐점.md   # 새 버전 올릴 준비 (테스트·앱·exe·서명한 latest.json)
```

**새 버전 내기**: `package.json`의 `version`을 올리고 `npm run release -- --notes-file …`을 실행하면
`dist\release\v<버전>\`에 올릴 파일이 생기고, 마지막에 GitHub에 올리는 `gh release create …` 명령을 보여 줍니다.
설치된 쏙들은 이 릴리스의 `latest.json`을 보고 업데이트합니다.
**업데이트 서명 키**는 `%USERPROFILE%\.ssok-release\update-key.pem`에 있습니다 (공개 키는 `src/update-key.js`).
저장소에 넣지 말고 꼭 따로 백업하세요. 잃어버리면 이미 설치된 쏙들에 자동 업데이트를 보낼 수 없습니다.

안드로이드 앱은 Gradle 없이 SDK 도구로 바로 빌드합니다. 필요한 것(관리자 권한 없이 사용자 폴더에 설치):
JDK 17 이상(`JAVA_HOME` 또는 `%LOCALAPPDATA%\Programs\jdk-*`),
Android SDK의 `platforms;android-35`, `build-tools;35.0.0`(`ANDROID_HOME` 또는 `%LOCALAPPDATA%\Android\Sdk`).
**서명 키**는 처음 빌드할 때 `%USERPROFILE%\.ssok-android`에 만들어집니다. 저장소에는 들어가지 않으니 꼭 따로 백업하세요.
이 키를 잃어버리면 이미 앱을 설치한 휴대폰에서는 앱을 지우고 다시 설치해야 업데이트할 수 있습니다.

| 파일 | 역할 |
| --- | --- |
| `server.js` | 실행 진입점: 설정, 포트 선택, 뒤에서 실행(--launch), 바로가기, 종료 처리 |
| `src/brand.js` | 프로그램 이름 (이름을 바꾸려면 이 파일만 고치면 됨) |
| `src/app.js` | HTTP·HTTPS 서버: 인증, 업로드·다운로드(Range 지원), 실시간 알림(SSE), 설정 |
| `src/peer-api.js` | 기기 연결(페어링)·해제, 연결된 PC로 파일·텍스트 중계, 바뀐 주소 확인 |
| `src/peers.js` | 연결된 기기·주변 PC 목록, 기기끼리 쓰는 암호화 요청, 확인 숫자 |
| `src/tls.js` | 자체 서명 인증서 만들기, 인증서 고정, 한 포트에서 HTTP·HTTPS 함께 받기 |
| `src/discovery.js` | 같은 네트워크의 쏙 자동 찾기 (UDP 8765 브로드캐스트) |
| `src/http.js` | 응답·본문 읽기 같은 공통 HTTP 도구 |
| `src/qr.js` | 외부 의존성 없는 QR 코드 생성기 (SVG·터미널 출력) |
| `src/files.js` | 파일 이름 정리, 이름 겹침 처리, MIME |
| `src/net.js` | 휴대폰이 접속할 IP 고르기, Host 헤더 검사, 브로드캐스트 주소 |
| `src/store.js` | 주고받은 목록 저장 |
| `src/logs.js` | 보낼 실행 기록에서 접속 코드 가리기 |
| `src/window.js` | 전용 창(Chrome·Edge 앱 창) 열기, 알림 영역 아이콘 |
| `src/open.js`, `src/windows.js` | 탐색기·브라우저 열기, 공용 네트워크 감지, 시작 메뉴·자동 실행 바로가기 |
| `public/` | 웹 화면 (PC·휴대폰 공용) |
| `scripts/make-icons.mjs` | `icon.svg`와 같은 모양의 PNG·ICO 아이콘 생성 |
| `scripts/package.mjs` | 나눠 줄 압축 파일 만들기 |
| `scripts/build-exe.mjs`, `src/exe.js` | 나눠 줄 exe 만들기 (Node.js 단일 실행 파일), exe의 스스로 설치·화면 파일 풀기 |
| `src/relay-client.js` | 어디서나: PC가 중계 서버에 붙어 있다가 휴대폰의 암호화된 요청을 이 PC의 쏙에 전달 |
| `public/relay.js` | 어디서나: 휴대폰·PC가 함께 쓰는 종단간 암호화 통로 (HKDF·AES-GCM, 요청·응답 나눠 보내기) |
| `src/relay-server.js`, `src/ws.js` | 중계 서버: 초대 코드·PC 연결·휴대폰과 PC 잇기, 의존성 없는 웹소켓 |
| `src/relay-host.js`, `src/relay-admin.js`, `public/relay-admin.*` | 중계 서버 모드: 설치·자동 실행·업데이트, 관리 화면 |
| `src/relay-rooms.js`, `public/room.*`, `public/room-core.js` | 홈페이지에서 바로 주고받기: 암호·입장권, 6자리 방(10대까지), 방 열쇠 건네기·암호화·받는 기기 지정, 주고받기 화면 |
| `src/drops.js`, `public/drop.*` | 링크로 주고받기: 링크 목록·비밀번호·기간, 쏙이 없는 사람이 여는 주고받기 화면 (중계 서버의 /<링크 이름>) |
| `src/relay-tunnel.js` | 다른 곳의 PC와 처음 연결할 때: 중계 통로를 소켓처럼 감싸 그 위에서 HTTPS로 연결 과정을 밟기 |
| `src/cloudflared.js` | Cloudflare 터널: cloudflared 내려받기, 로그인·터널·DNS, 켜 두기 |
| `src/update.js`, `src/update-key.js` | 새 버전 확인·내려받기·서명 확인, 업데이트 공개 키 |
| `scripts/release.mjs` | 새 버전 올릴 준비 (exe·apk·서명한 latest.json) |
| `android/` | 안드로이드 앱: 공유 받기(`ShareActivity`), 보내기 서비스(`UploadService`), PC 연결(`PairActivity`), 암호화 통신(`Net`) |
