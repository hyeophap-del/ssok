휴대폰에서 접속이 안 되나요?
  1. 같은 Wi-Fi에 연결되어 있는지 확인하세요. 게스트 Wi-Fi는 기기끼리 통신이 막혀 있을 수 있어요.
  2. 처음 실행할 때 뜬 Windows 방화벽 창에서 ‘허용’을 눌러야 해요. 놓쳤다면 Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용에서 Node.js를 체크하세요.
  3. Wi-Fi가 ‘공용 네트워크’면 막힐 수 있어요. 설정 → 네트워크 및 인터넷 → Wi-Fi → 연결된 Wi-Fi에서 ‘개인 네트워크’로 바꾸세요.
  4. 네트워크가 여러 개라면 위에서 다른 네트워크를 골라 다시 스캔해 보세요.
