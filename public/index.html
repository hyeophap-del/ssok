휴대폰 연결

휴대폰 카메라로 QR 코드를 스캔하면 바로 열려요.

집 밖에서도 쓰려면?
  1. 이 PC와 휴대폰에 무료 앱 Tailscale을 설치해요 (tailscale.com/download, 휴대폰은 앱 스토어에서 ‘Tailscale’).
  2. 두 기기 모두 같은 계정(구글 등)으로 로그인하고 연결을 켜요.
  3. 잠시 뒤 이 카드에 [어디서나] 탭이 생기면, 그 QR을 휴대폰으로 스캔해요. 그 주소는 집에서도 밖에서도 열려요.

휴대폰에서 접속이 안 되나요?
  1. 같은 Wi-Fi에 연결되어 있는지 확인하세요. 게스트 Wi-Fi는 기기끼리 통신이 막혀 있을 수 있어요.
  2. 처음 실행할 때 뜬 Windows 방화벽 창에서 ‘허용’을 눌러야 해요. 놓쳤다면 Windows 보안 → 방화벽 및 네트워크 보호 → 방화벽에서 앱 허용에서 Node.js를 체크하세요.
  3. Wi-Fi가 ‘공용 네트워크’면 막힐 수 있어요. 설정 → 네트워크 및 인터넷 → Wi-Fi → 연결된 Wi-Fi에서 ‘개인 네트워크’로 바꾸세요.
  4. 네트워크가 여러 개라면 위에서 다른 네트워크를 골라 다시 스캔해 보세요.

아이폰: 사진 앱의 공유 메뉴에서 바로 보내기

아이폰 기본 앱인 단축어로 공유 메뉴에 ‘{{APP_NAME}}으로 보내기’를 한 번만 만들어 두면, 이 화면을 열지 않아도 PC로 보낼 수 있어요.

  1. 단축어 앱을 열고 오른쪽 위 +를 눌러 새 단축어를 만들어요.
  2. 동작 추가에서 ‘반복’을 검색해 각각 반복(Repeat with Each)을 넣어요. 반복할 대상은 단축어 입력이에요.
  3. 반복 안에 ‘URL’을 검색해 URL 콘텐츠 가져오기(Get Contents of URL)를 넣고, URL 자리에 아래 주소를 붙여 넣어요.
  4. 그 동작을 펼쳐서 방법: POST, 요청 본문: 파일로 바꾸고, 파일에는 반복 항목을 골라요.
  5. 아래쪽 ⓘ를 눌러 공유 시트에서 보기를 켜고, 단축어 이름을 ‘{{APP_NAME}}으로 보내기’로 바꿔요.
  6. 이제 사진 앱에서 공유 → {{APP_NAME}}으로 보내기를 누르면 PC의 받은 파일 폴더로 가요. 텍스트·링크도 돼요.

이 주소에는 PC 접속 코드가 들어 있으니 다른 사람에게 보여 주지 마세요. PC의 IP 주소가 바뀌면 주소를 다시 붙여 넣어야 해요.
